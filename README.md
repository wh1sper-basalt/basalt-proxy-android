**Basalt Proxy** – это локальный **MTProto-прокси** для Telegram на Android. Приложение помогает частично решать проблемы с подключением и в ряде сценариев ускоряет работу мессенджера, перенаправляя трафик через защищённые CloudFlare WebSocket-соединения или напрямую к датацентрам Telegram.

## Возможности

### Ядро прокси
- **Локальный MTProto-прокси** на базе нативного движка на языке **Rust**.
- **Два маршрута:** через CloudFlare WebSocket и напрямую к датацентрам Telegram с автоматическим fallback между ними.
- **Пул WebSocket-соединений** с предварительным прогревом, keepalive-механикой и автоматической ротацией протухших.
- **Умное переключение DC** с cooldown-логикой, чёрным списком и параллельными попытками.
- **Свой DoH-резолвер** (Cloudflare, Google, Quad9, AdGuard) с параллельными запросами и кешированием.
- **Обработка 429-ответов** от CloudFlare с экспоненциальным cooldown'ом.

### Интеграция с Telegram
- Кнопка **«Применить в Telegram»** автоматически передаёт прокси в совместимые клиенты через `tg://proxy` (AyuGram, Plus Messenger, NekoGram, Cherrygram, MDGram и другие).
- Работает с официальным клиентом Telegram и большинством сторонних.

### Фоновый режим
- **Foreground Service** с уведомлением о статусе работы.
- **WakeLock** с периодическим обновлением, чтобы Android не выгружал прокси.
- **Автозапуск после перезагрузки устройства** (опционально).
- **Восстановление после kill** – сервис поднимается заново с сохранёнными настройками.

### Интерфейс
- **Material 3 + Jetpack Compose** – современный UI под актуальный Android.
- **4 экрана:** Прокси, Настройки, Логи, Информация.
- **Плавные анимации** – переключение вкладок свайпом с интерактивным индикатором, анимированное раскрытие блоков, плавная смена фильтров, fade при смене языка с полноэкранным блюром.
- **Лог-вьюер в реальном времени** с фильтрами INFO / ERROR / NULL (мультивыбор: INFO + ERROR работают одновременно).
- **Автоскролл** терминала и лога, кнопка копирования отчёта.

### Темы и оформление
- **Динамические цвета** (Material You) на Android 12+.
- **5 встроенных палитр:** Indigo, Forest, Espresso, Pink (пастельный), Mono (монохром).
- **Особая тема Basalt** – кастомный фон, логотип-камень, приглушённые акценты.
- **Светлая и тёмная темы** + системная.
- **Плавное переключение языка** (RU / EN) без чёрного кадра: экран плавно заблюривается, язык меняется, блюр плавно снимается.

### Прочее
- **Виброотклик** с настройкой силы (0–10) и выбором режима: на все кнопки или только на главную кнопку вкл/выкл.
- **Авто-обновления** – приложение само проверяет GitHub releases и показывает уведомление о новой версии.
- **Раздел «Информация»** с расширенной справкой по CloudFlare, пулу WS, ручной настройке DC.
- **Сбор отчёта** одним тапом – версия, ABI, SoC, ROM, настройки, последние ошибки.

## Как это работает

```text
Telegram Android → Локальный MTProto (127.0.0.1:1337) → Basalt Proxy → WSS (CloudFlare / напрямую) → Telegram DC
1. Приложение поднимает локальный MTProto-прокси средствами нативного движка на Rust.
2. Перехватывает подключения Telegram через локальный порт и сгенерированный секретный ключ.
3. Извлекает DC ID из handshake-пакета и открывает WebSocket (TLS) с нужным датацентром, при необходимости – через CloudFlare.
4. Держит пул готовых соединений, ротирует протухшие, использует fallback-сценарии (Worker → CF → TCP) при провале маршрута.
```

## Быстрый старт

1. Скачайте актуальный APK со страницы релизов.
2. Установите приложение на Android-устройство (Android 7.0+ для 32-бит, Android 8.0+ для 64-бит).
3. Откройте Basalt Proxy и ознакомьтесь со справкой внутри приложения.
4. Нажмите «Запустить прокси» – появится уведомление о работе в фоне.
5. Нажмите «Применить в Telegram» – откроется Telegram-клиент, где нужно подтвердить подключение.

По умолчанию прокси работает на 127.0.0.1:1337. Порт можно изменить в настройках.

## Сборка из исходников

**Требуется:**
- JDK 17
- Android SDK с NDK 24+
- Rust 1.70+ с rustup
- cargo install cargo-ndk
- rustup target add aarch64-linux-android armv7-linux-androideabi

**Сборка нативной библиотеки:**
```bash
build_so.bat
```

**Сборка APK:**

```bash
build_apk.bat
```

## Отчёты об ошибках

Если возникают сбои, вылеты или ошибки при работе – сохраняйте отчёты и открывайте issue с технической информацией.

```text
Внутри приложения есть кнопка «Собрать отчёт» – она собирает версию, ABI, модель устройства, SoC, ROM, настройки и последние ошибки. Скопируйте и приложите к issue.
Мелкие ошибки в логах при нормально работающем прокси можно игнорировать.
```

Перед созданием issue попробуйте:

- Перезапустить прокси (кнопка Restart в уведомлении). 
- Сравнить поведение с включённым и выключенным CloudFlare.
- Проверить другую сеть (Wi-Fi / мобильные данные).
